This document describes every module in the project — both Backend (FastAPI/Python)
and Frontend (React/Vite). The project follows a role-based supply chain management
system with AI-driven inventory rebalancing, forecasting, and real-time notifications.

================================================================================
                              PROJECT OVERVIEW
================================================================================

The application is a full-stack Smart Supply Chain AI platform that allows
organizations to manage products, inventory, suppliers, sales, forecasting,
and depot-to-depot inventory rebalancing across multiple user roles
(Admin, HOD, Manager, Employee).

Tech Stack:
  - Backend  : Python, FastAPI, SQLAlchemy (ORM), SQLite/MySQL
  - Frontend : React 19, Vite, Tailwind CSS, Recharts, Framer Motion
  - Real-time: WebSockets (via Redis pub/sub)
  - AI Engine: Custom AI service for demand forecasting & rebalancing logic
